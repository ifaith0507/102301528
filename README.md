# 校园失物招领处

> 2026 秋软件工程结对作业

基于第一次结对作业的需求分析与墨刀原型设计，实现了"发布信息—浏览或搜索—查看详情—联系发布者—更新状态"的完整核心流程。

## 设计理念

以校园失物招领处的**「招领票根」**为视觉概念：
- 红 = 寻物（急）· 绿 = 招领（已收好）· 墨 = 中性操作 · 黄 = 胶带高亮
- 卡片采用票根撕边 + 打孔 + 橡皮图章设计
- 手机外框模拟移动端真机体验

## 功能一览

| 功能 | 说明 |
|------|------|
| 🏠 首页 | 票根式卡片列表，统计概览，类型切换（全部/寻物/招领） |
| 🔍 搜索 | 关键词模糊匹配（名称/类别/地点/描述），热门词快捷搜索 |
| ➕ 发布 | 寻物/招领类型选择，类别标签，时间选择器，图片上传，表单验证 |
| 📋 详情 | Hero 区展示，规格表，联系方式模糊显示（点击展开），状态图章 |
| 👤 我的发布 | 查看自己发布的全部信息，标记已找到/已归还，撤回状态，删除 |
| ✅ 发布成功 | 印章盖章动画，信息回执 |
| 📊 状态管理 | 发布者可将信息标记为"已找到"或"已归还"，减少重复询问 |

## 使用说明

### 1. 浏览信息
打开 `index.html` 进入首页，可看到统计概览和票根式信息卡片。点击卡片进入详情。

### 2. 搜索与筛选
点击首页搜索框进入搜索页，输入关键词（如「校园卡」「雨伞」），或点击热门词标签快捷搜索。可切换全部/寻物/招领。

### 3. 发布信息
点击底部导航「发布」按钮，选择类型（寻物/招领），填写带 * 的必填项，可选上传图片，点击「发布」。

### 4. 查看详情
在详情页查看物品规格表、详细描述和联系方式。非发布者需点击「显示」展开联系方式（防爬取）。

### 5. 更新状态
在详情页或「我的发布」页面，发布者可标记「已找到/已归还」，盖章动效反馈。也可撤回状态或删除。

## 技术说明

- **纯前端实现**：HTML + CSS + JavaScript，无后端依赖，用 `localStorage` 持久化数据
- **单页应用 (SPA)**：屏幕切换 + 历史栈实现页面导航
- **数据安全**：所有用户输入经 `esc()` 转义，防止 XSS 注入
- **设计系统**：CSS 变量统一管理颜色、字体、圆角、阴影
